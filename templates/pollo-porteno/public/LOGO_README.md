# Pollo Porteño Logo

The official brand logo (chicken giving thumbs up next to the grill house, with
red curved "POLLO PORTEÑO" lettering) should be saved here as:

- `public/logo.png` – primary logo used in the header and hero (recommended ≥ 800x800).
- `public/favicon.svg` – simplified favicon (already provided).

A temporary `public/logo.svg` placeholder is included until the official PNG is
dropped in. The components reference `/logo.png` first; rename or replace as
needed in `index.html` and the components if the file extension changes.
